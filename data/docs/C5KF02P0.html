C5KF02P0Procédure d’initialisation : Motoréducteur de toit ouvrant
TOIT OUVRANT CDE ASSIST SEQUENT+ANTI PINCEMENT
IMPERATIF : Le temps imparti entre les différentes étapes d’initialisation est de 5 secondes, l’opérateur doit prendre connaissance de la procédure complète.
ATTENTION : Si le temps imparti entre les différentes étapes d’initialisation est supérieur à 5 secondes, la procédure d’initialisation doit être recommencée depuis le début.
1. Applications
Effectuer une procédure d’initialisation dans les cas suivants :
  • La position zéro "0" du bouton rotatif ne correspond pas à la position zéro du motoréducteur (position toit fermé)
  • Le toit ouvrant ne s’ouvre pas à l’aide du bouton rotatif
  • Le toit ouvrant ne se referme pas à cause de l’antipincement
ATTENTION : La tension de la batterie doit être supérieure à 13 volts (moteur du véhicule tournant).
2. Procédure de réinitialisation (motoréducteur de toit ouvrant initialisé)
Placer le bouton rotatif sur la position zéro "0".
Attendre la fermeture complète ou l’arrêt du toit ouvrant.
2.1. 1er cas : Le toit ouvrant se déplace vers l’arrière (antipincement)
Effectuer les opérations suivantes :
  • Attendre 5 secondes, après l’arrêt du déplacement vers l’arrière
  • Appuyer sur le bouton rotatif jusqu’à la fermeture du toit ouvrant
  • Maintenir l’appui sur le bouton rotatif 2 à 3 secondes
  • Relâcher le bouton rotatif
2.2. 2ème cas : Le toit ouvrant s’arrête (position ouverte)
Effectuer les opérations suivantes :
  • Appuyer sur le bouton rotatif jusqu’à la fermeture du toit ouvrant (déclic du relais du motoréducteur)
  • Maintenir l’appui sur le bouton rotatif 2 à 3 secondes
  • Relâcher le bouton rotatif
2.3. Réinitialisation
Effectuer les opérations suivantes :
  • Placer le bouton rotatif en position ouverture maximale
  • Appuyer sur le bouton rotatif jusqu’à l’ouverture maximale du toit ouvrant
  • Maintenir l’appui sur le bouton rotatif 2 à 3 secondes
  • Relâcher le bouton rotatif
  • Sans appuyer, placer le bouton rotatif directement en position zéro "0" (si le toit ouvrant se déplace, recommencer la procédure de réinitialisation)
  • Appuyer sur le bouton rotatif jusqu’à la fermeture du toit ouvrant (le déplacement s’effectue après 1 seconde)
  • Maintenir l’appui sur le bouton rotatif 2 à 3 secondes
  • Relâcher le bouton rotatif
3. Contrôle
Placer le bouton rotatif sur les différentes positions pour contrôler l’ouverture et la fermeture séquentielle du toit ouvrant (si anomalie, recommencer la réinitialisation).
4. Procédure d’initialisation (motoréducteur neuf)
Effectuer les opérations suivantes :
  • Placer le bouton rotatif sur la position zéro "0"
  • Appuyer sur le bouton rotatif jusqu’à la fermeture du toit ouvrant (déclic du relais du motoréducteur)
  • Maintenir l’appui sur le bouton rotatif 2 à 3 secondes
  • Relâcher le bouton rotatif
  • Placer le bouton rotatif en position ouverture maximale
  • Appuyer sur le bouton rotatif jusqu’à l’ouverture maximale du toit ouvrant
  • Maintenir l’appui sur le bouton rotatif 2 à 3 secondes
  • Relâcher le bouton rotatif
  • Sans appuyer, placer le bouton rotatif directement en position zéro "0" (si le toit ouvrant se déplace, recommencer la procédure d’initialisation)
  • Appuyer sur le bouton rotatif jusqu’à la fermeture du toit ouvrant (le déplacement s’effectue après 1 seconde)
  • Maintenir l’appui sur le bouton rotatif 2 à 3 secondes
  • Relâcher le bouton rotatif
5. Contrôle
Placer le bouton rotatif sur les différentes positions pour contrôler l’ouverture et la fermeture séquentielle du toit ouvrant (si anomalie, recommencer l’initialisation).
