B3FG39P0Dépose - repose : Amplificateur de freinage
DEPUIS OPR 9128
IMPERATIF : Respecter les précautions à prendre avant intervention (se reporter à la brochure "RECOMMANDATIONS - PRÉCAUTIONS").
1. Dépose
1.1. Côté moteur
Débrancher la batterie .
Déposer :
  • Le boîtier de filtre à air
  • Le bac à batterie
  • Les calculateurs
NOTA : Protéger les organes placés sous le maître-cylindre de frein des projections de liquide de frein.
Figure : b3fp167c
Déposer le maître-cylindre de frein ( 1) (voir opération correspondante).
Désaccoupler le tube de dépression ( 2) de l’amplificateur de freinage.
1.2. Côté habitacle
Déposer le cache pédalier.
Figure : b3fp168c
Dégrafer l’axe ( 3).
Déposer :
  • Les écrous (4)
  • L’amplificateur de freinage
NOTA : L’amplificateur de freinage est collé sur le tablier, le déposer avec précaution et nettoyer les surfaces en contact.
2. Repose
Figure : b3fp169d
Coller un joint neuf ( 5) sur l’amplificateur de freinage.
Reposer :
  • L’amplificateur de freinage
  • Les écrous (4)
Serrer les écrous (4) à 2,2 ± 0,3 m.daN.
Agrafer l’axe ( 3).
Reposer :
  • Le cache pédalier
  • Le tube de dépression (2)
  • Le maître-cylindre de frein (voir opération correspondante)
  • Le bac à batterie
  • Le boîtier de filtre à air
Purger le circuit de freinage (voir opération correspondante).
