B1HDESP0Contrôle : Pression carburant (flex fuel)
IMPERATIF : Respecter les consignes de sécurité et de propreté.
1. Outillage préconisé
Figure : e5ap2pqd
[ 1] manomètre 2279-T.bis du coffret 4103-T.
Figure : e5ap1tjc
[ 2] raccord pour prise de pression carburant 4192-T.
2. Contrôle de la pression
Figure : b1bp3gtd
Assembler l’outil [ 1] avec l’outil [2].
ATTENTION : Lors de l’accouplement des outils [ 1] et [2], se protéger à l’aide d’un chiffon afin d’éviter toutes projections de carburant.
Raccorder l’outil [ 2] sur la valve de purge du circuit d’alimentation carburant en "a".
Démarrer le moteur.
Relever les pressions.
Pression de fonctionnement 4,2 bars.
Arrêter le moteur.
ATTENTION : Lors du désaccouplement des outils [ 1] et [2], se protéger à l’aide d’un chiffon afin d’éviter toutes projections de carburant.
Désaccoupler l’outil [ 2] et recueillir le carburant dans un récipient.
