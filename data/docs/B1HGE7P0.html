B1HGE7P0Dépose - repose : Détendeur GNV
IMPERATIF : Respecter les consignes de sécurité applicables lors des interventions sur circuit GNV (voir opération correspondante).
IMPERATIF : Toute intervention sur un véhicule fonctionnant avec du gaz doit s’effectuer dans un local aéré.
1. Outillage préconisé
Figure : e5ap2cfc
[ 1] pince pour collier OETIKER (-).1615.
Figure : e5-p08hc
[ 2] jeux de deux pince-durits 4153-T.
2. Dépose
IMPERATIF : Effectuer la mise hors pression du circuit d’alimentation GNV (voir opération correspondante).
Débrancher la batterie .
Figure : b1bp3cxc
Positionner les outils [ 2] sur les durits (1).
Désaccoupler les durits (1).
ATTENTION : Repérer le positionnement des durits ( 1) sur le détendeur GNV (entrée et sortie du liquide de refroidissement).
Figure : b1bp3cyc
Déconnecter le connecteur "a".
Desserrer le raccord (2).
NOTA : Un peu de gaz peut s’échapper dans l’atmosphère si la canalisation est encore sous pression.
Désaccoupler le tuyau de dépression ( 3).
Figure : b1hp24sc
Couper le collier ( 4).
Désaccoupler la durit d’alimentation GNV ( 6).
Déposer :
  • Les 4 vis (5)
  • Le détendeur GNV (7)
IMPERATIF : Obturer les orifices du détendeur (GNV).
3. Repose
Reposer :
  • Le détendeur GNV ( 7)
  • Les 4 vis (5)
Accoupler au détendeur GNV :
  • Les durits de réchauffage ( 1)
  • La durit d’alimentation GNV (6)
  • Le tuyau de dépression (3)
IMPERATIF : Poser un collier ( 4) neuf.
Serrer le collier (4) À l’aide de l’outil [1].
Serrer le raccord ( 2) à la main jusqu’au contact puis serrer d’un quart de tour (90°).
Connecter le connecteur en " a".
4. Opérations complémentaires
Rebrancher la batterie.
Démarrer le moteur.
Passer en mode GNV.
Vérifier l’absence de fuite sur le raccord ( 2) (voir opération correspondante).
