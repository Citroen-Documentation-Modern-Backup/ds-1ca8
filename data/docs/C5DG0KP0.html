C5DG0KP0Reconversion : Véhicule auto-école en véhicule particulier
DEPUIS OPR 9457
NOTA : Il est possible de déséquiper un véhicule auto-école sans déposer la planche de bord.
1. Opérations à réaliser
Déposer :
  • Le pédalier double-commande
  • La plaque constructeur complémentaire "auto-école"
  • Le rétroviseur extérieur additionnel côté passager
  • Le rétroviseur intérieur additionnel auto-école et son support
  • Le boîtier de commande moniteur auto-école
Télécoder le boîtier de servitude intelligent (BSI).
2. Pédalier double-commande
2.1. Côté passager

  • La boîte de rangement (voir opération correspondante)
  • Les garnissages sous planche de bord (voir opération correspondante)

2.3. Plaque constructeur complémentaire "auto-école"
Déposer la plaque constructeur complémentaire "auto-école" située à côté de la plaque constructeur.
2.4. Rétroviseur additionnel extérieur
Déposer le rétroviseur additionnel extérieur.
2.5. Rétroviseur intérieur additionnel et support
Figure : c5gp0bhc
Déposer :
  • Les rétroviseurs ( 37)
  • Le support double (35)
Poser un des rétroviseurs ( 37) sur le support d’origine (36).
2.6. Boîtier de commande moniteur
Déclipper :
  • Le boîtier de commande moniteur de son support
  • Le support du boîtier de commande moniteur
Ranger le faisceau restant dans la planche de bord.
Reposer un vide-poches d’origine à l’emplacement du module double commande.
3. Télécodage du boîtier de servitude intelligent (BSI)
3.1. Procédure de télécodage À l’aide de l’outil de diagnostic "LEXIA"
Effectuer les sélections suivantes dans l’outil de diagnostic :
  • Sélectionner le menu "Diagnostic"
  • Sélectionner le véhicule "CITROËN 3"
  • Saisir le numéro OPR
  • Sélectionner le menu "Test Global"
  • Sélectionner le calculateur boîtier de servitude intelligent "BSI"
  • Sélectionner le menu "TÉLÉCODAGE"
  • Sélectionner le menu "TÉLÉCODAGE MANUEL"
  • Sélectionner le menu "TÉLÉCODAGE MANUEL SANS DONNÉES"
  • Sélectionner le menu "CONFIGURATION"
  • Sélectionner le menu "CONFIGURATION"
  • Télécoder le paramètre "option auto-école" à la valeur "Absente"
  • Appuyer sur la touche (F1) pour effectuer le télécodage
  • Renseigner le code d’accès
  • Couper le contact
  • L’outil de diagnostic confirme que le télécodage des options de configuration s’est bien effectué
  • Appuyer sur la touche retour (F9)
  • Mettre le contact
  • Appuyer sur la touche retour (F9)
  • Sélectionner le menu "CALCULATEURS PRÉSENTS"
  • Télécoder le paramètre "module auto-école" à la valeur "absent"
  • Appuyer sur la touche (F1) pour effectuer le télécodage
  • Renseigner le code d’accès
  • Couper le contact
  • L’outil de diagnostic confirme que le télécodage des calculateurs présents s’est bien effectué
3.2. Procédure de télécodage À l’aide de l’outil de diagnostic "PROXIA"

  • Sélectionner le menu "CONFIGURATION"
  • Sélectionner le menu "CONFIGURATION"
