D4EB4LP0Présentation : Écran multifonction
DEPUIS OPR 9527
1. Préambule
L’écran multifonction n’est pas qu’un support d’information pour le conducteur, c’est un calculateur du réseau VAN CONFORT qui a les fonctionnalités suivantes :
  • Informer le conducteur sur des éléments extérieurs au système (date, heure, température extérieure)
  • Informer le conducteur sur des éléments internes au système (autodiagnostic, ordinateur de bord)
  • Piloter l’autoradio et gérer son affichage (*)
  • Piloter le changeur CD et gérer son affichage (*)
  • Piloter le système de navigation et gérer son affichage (*)
  • Piloter le radiotéléphone et gérer son affichage (*)
(*) Selon équipement.
Il existe 6 écrans multifonctions différents :
  • Écran multifonction de type A
  • Écran multifonction de type B
  • Écran multifonction de type C (équipé avec le système de guidage "monochrome")
  • Écran multifonction de type D (équipé avec le système de guidage "couleur")
  • Écran multifonction de type Ct (voir radiotéléphone RT3)
  • Écran multifonction de type Dt (voir radiotéléphone RT3)
Il existe 3 niveaux de radiotéléphone (RT3) :
  • niveau 1+ : Radiotéléphone (RT3) avec les fonctionnalités autoradio, téléphone et système de guidage embarqué avec un écran monochrome Ct
  • niveau 3 : Radiotéléphone (RT3) avec les fonctionnalités autoradio, téléphone et système de guidage embarqué avec un écran couleur Dt
NOTA : Le système télématique radiotéléphone (RT3) se compose de deux éléments (écran Ct et Dt) et d’un boîtier télématique.
2. Fonctions associées à l’écran multifonction
L’écran multifonction affiche des informations diverses :
  • heure
  • Date
  • Format d’affichage date et heure
  • Température extérieure
  • Autoradio
  • Changeur CD
  • Ordinateur de bord
  • Téléphone intégré à l’autoradio
  • Aide au stationnement
  • État des ouvrants
  • Alertes véhicules et informations
3. Gestion des appuis
Différents types d’appuis permettent d’utiliser les écrans :
  • Appui simple : Dès la détection de l’appui
  • Appui court : Dès que le bouton est relâché, avant le délai de l’appui long
  • Appui long : Au-delà d’un délai T
  • Appui maintenu À l’issue du délai de l’appui long, l’information est envoyée périodiquement toutes les 200 ms pendant le temps de maintien de la touche

7. Écran multifonction de type Ct
L’écran multifonction a pour rôle d’informer les utilisateurs sur l’état des fonctions suivantes :
  • Radio
  • Lecteur CD
  • Navigation
  • Services
  • OdB
  • Alertes véhicules
  • Configuration
  • Etc.
Il doit gérer en plus son propre contraste grâce à un capteur de luminosité interne.
L’écran Ct est en liaison directe avec le radiotéléphone RT3 par le biais d’une liaison CAN. Il n’est en relation avec aucun autre élément du véhicule.

8. Écran multifonction de type DT
L’écran multifonction a pour rôle d’informer les utilisateurs sur l’état des fonctions suivantes :
  • Radio
  • Lecteur CD
  • Navigation
  • Services
  • OdB
  • Alertes véhicules
  • Configuration
  • Etc.
Il doit gérer en plus son propre contraste grâce à un capteur de luminosité interne.
L’écran DT est en liaison directe avec le radiotéléphone RT3 par le biais d’une liaison par fibre optique. Il est également en relation par le biais d’entrées vidéo externes avec un camescope ou un tuner TV par exemple.
L’écran est composé de 3 modules : Un écran LCD, une carte graphique et un capteur de luminosité.
