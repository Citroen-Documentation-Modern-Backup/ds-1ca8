2. Test actionneur
Il est possible d’effectuer les tests suivants à l’aide de l’outil de diagnostic
Intitulé Précisions sur l’activation (durée, fréquence, cycle) Message associé Codification
Moteur recyclage(*) Effectuer 2 cycles. (1 cycle = 0 à 100 % + 100 à 0 %) Vérifier les 2 cycles d’aller/retour du moteur ACTRECYCLAGE
Moteur distribution(*) Effectuer 2 cycles. (1 cycle = 0 à 100 % + 100 à 0 %) Vérifier les 2 cycles d’aller/retour du moteur ACTDISTRIBUTION
Moteur mixage(*) Effectuer 2 cycles. (1 cycle = 0 à 100 % + 100 à 0 %) Vérifier les 2 cycles d’aller/retour du moteur ACTMIXAGE
Allumage afficheur Effectuer 2 cycles. (1 cycle = 1 allumage + 1 extinction) Vérifier les 2 cycles d’allumage et d’extinction de l’afficheur ACTAFFICHEURS
Niveau éclairage Effectuer 2 cycles. (1 cycle = 1 à 16 + 1 à 16 niveaux d’éclairement) Vérifier les 2 cycles d’éclairage progressif ACTECLAIRAGE
Moteur pulseur(**) Effectuer 2 cycles. (1 cycle = 1 montée progressive vitesse pulseur + 1 descente progressive de la vitesse) Vérifier les 2 cycles de montées et de descentes progressives de la vitesse du pulseur ACTPULSEUR
touches Effectuer 2 cycles. (1 cycle = 1 allumage + 1 extinction) Vérifier les 2 cycles d’allumage et d’extinction de l’afficheur ACTTOUCHE
( *) : Pour entendre l’activation de l’élément, effectuer les tests actionneurs à l’intérieur du véhicule, vitres et portières fermées.
( **) : Le test actionneur moteur pulseur s’effectue moteur tournant.
3. Télécodage
Il est possible de télécoder les paramètres suivants à l’aide de l’outil de diagnostic :
  • Unité de température : °C ou °F
  • Type de motorisation : Non HDI ou HDI
  • Type de véhicule : Nom commercial du véhicule(C3...)
  • Destination : Europe, Mercosur, Asie
