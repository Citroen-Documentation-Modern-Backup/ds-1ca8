C5GS0BP0Déshabillage - Habillage : Banquette arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté (se reporter à la brochure "RECOMMANDATIONS - PRÉCAUTIONS").
1. Opération préliminaire
Déposer la banquette arrière (voir opération correspondante).
2. Déshabillage
Figure : c5gp09ac
Tirer l’appui-tête ( 1) jusqu’à la butée de fin de course (suivant flèche ).
Appuyer sur le bouton en " a" pour déverrouiller la fin de course.
Déposer l’appui-tête (1).
Figure : c5gp09bc
Dégrafer le garnissage ( 2) (en "b").
Figure : c5gp09cc
Dégrafer le garnissage des supports d’appui-tête (en "c").
Déposer :
  • Les 2 vis (4)
  • Le cache (3)
Figure : c5gp09dc
Déposer :
  • La vis (6)
  • Le support (5)
Figure : c5gp09ec
Déclipper les supports d’appui-tête ( 7) (en "d").
Figure : c5gp09fc
Déclipper le cache du verrouillage ( 8) de dossier.
Déposer l’ensemble mousse et garnissage.
3. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
